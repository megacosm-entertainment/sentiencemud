# Crypto Modernization Phase 2 - OTP & Key Management

## Overview

Complete the crypto modernization by migrating OTP key encryption to authenticated encryption, hashing recovery codes, and integrating passphrase-based key derivation with game_settings.

## Current State

### What We've Done (Phase 1)
✅ Password hashing migrated to Argon2id
✅ Automatic password migration on login
✅ Bootstrap uses Argon2id
✅ Created authenticated encryption functions (encrypt_string_v2/decrypt_string_v2)
✅ Staff migration monitoring command (pwmigrate)

### What's Still Legacy
❌ **OTP keys**: Still using AES-256-CBC (v1) without MAC - vulnerable to padding oracle attacks
❌ **Recovery codes**: Stored in plaintext - should be hashed
❌ **Crypto key**: Stored in plaintext file - should support passphrase derivation
❌ **Key rotation**: No mechanism for rotating encryption keys

## Phase 2 Goals

1. **Migrate OTP encryption** to XSalsa20-Poly1305 (authenticated)
2. **Hash recovery codes** instead of plaintext storage
3. **Integrate with game_settings** for crypto key passphrase
4. **Support key rotation** through game_settings

### Part 2: Crypto Key Derivation

#### Update handler.c crypto_init()

**Current:**
```c
void crypto_init(void) {
    FILE *fp = fopen("data/system/.crypto_key", "r");
    // ... read 32-byte key from file
}
```

**New:**
```c
void crypto_init(void) {
    // Check if passphrase-based derivation is enabled
    if (game_settings.crypto_use_passphrase) {
        // Derive key from passphrase using Argon2id
        crypto_init_from_passphrase(
            game_settings.crypto_key_passphrase,
            game_settings.crypto_key_version
        );
    } else {
        // Fallback to file-based key (backward compatible)
        crypto_init_from_file();
    }
}
```

#### Implement Passphrase-Based Key Derivation

```c
bool crypto_init_from_passphrase(const char *passphrase, int key_version) {
    unsigned char salt[crypto_pwhash_SALTBYTES];
    char salt_file[256];

    // Salt file includes version for key rotation
    snprintf(salt_file, sizeof(salt_file),
             "data/system/.crypto_salt_v%d", key_version);

    // Load or generate salt
    if (!load_or_generate_salt(salt_file, salt)) {
        return false;
    }

    // Derive 32-byte key using Argon2id
    if (crypto_pwhash(
        crypto_key,
        sizeof(crypto_key),
        passphrase,
        strlen(passphrase),
        salt,
        crypto_pwhash_OPSLIMIT_MODERATE,
        crypto_pwhash_MEMLIMIT_MODERATE,
        crypto_pwhash_ALG_DEFAULT
    ) != 0) {
        return false;
    }

    key_initialized = true;
    return true;
}
```

**Benefits:**
- Key derived from passphrase (can be in env var or Doppler)
- Salt stored on disk (public, doesn't need protection)
- Key version enables rotation
- Compatible with Kubernetes secrets, Doppler, etc.

### Part 3: OTP Key Migration

#### Add Encryption Version Detection

**Location:** `/sentience/src/handler.c` or new file

```c
typedef enum {
    ENCRYPT_V1_AES_CBC,      // Legacy AES-256-CBC (no MAC)
    ENCRYPT_V2_SECRETBOX     // XSalsa20-Poly1305 (authenticated)
} encrypt_version_t;

encrypt_version_t detect_encryption_version(const char *ciphertext) {
    // v2 format: "v2:" + base64(nonce + mac + ciphertext)
    if (strncmp(ciphertext, "v2:", 3) == 0) {
        return ENCRYPT_V2_SECRETBOX;
    }

    // v1 format: plain base64 (no prefix)
    return ENCRYPT_V1_AES_CBC;
}
```

#### Create Universal Decrypt Function

```c
char *decrypt_string_auto(const char *ciphertext) {
    encrypt_version_t version = detect_encryption_version(ciphertext);

    switch (version) {
        case ENCRYPT_V2_SECRETBOX:
            // Skip "v2:" prefix
            return decrypt_string_v2(ciphertext + 3, crypto_key);

        case ENCRYPT_V1_AES_CBC:
            // Legacy decryption
            return decrypt_string(ciphertext);

        default:
            return NULL;
    }
}
```

#### Update encrypt_string_v2 to Add Version Prefix

```c
char *encrypt_string_v2(const char *plaintext, const unsigned char *key) {
```

#### Migration Strategy for OTP Keys

**Trigger points:**
1. **On MFA setup** - New keys use v2 encryption
2. **On MFA verification** - Re-encrypt v1 keys to v2
3. **On account load** - Check and flag for migration

**Implementation:**
```c
bool migrate_otp_key_if_needed(ACCOUNT_DATA *acct) {
    if (IS_NULLSTR(acct->mfa_key))
        return true;

    // Check if already v2
    if (strncmp(acct->mfa_key, "v2:", 3) == 0)
        return true;

    // Decrypt with v1
    char *plaintext = decrypt_string(acct->mfa_key);
    if (!plaintext)
        return false;

    // Re-encrypt with v2
    char *encrypted_v2 = encrypt_string_v2(plaintext, crypto_key);

    // Update account
    free_string(acct->mfa_key);
    acct->mfa_key = str_dup(encrypted_v2);

    // Clean up
    free_string(plaintext);
    free_string(encrypted_v2);

    // Save
    save_account(acct);

    log_message_f(LOG_LEVEL_INFO, LOG_SECURITY,
        "Migrated OTP key to v2 encryption: %s", acct->username);

    return true;
}
```

### Part 4: Recovery Code Hashing

#### Current State
Recovery codes stored in plaintext:
```c
char *recovery_codes[MFA_RECOVERY_CODES];  // e.g., "ABCD-1234-EFGH-5678"
bool recovery_used[MFA_RECOVERY_CODES];
```

#### New Approach: Hash Recovery Codes

**Generate recovery codes:**
```c
void generate_recovery_codes(char *codes[MFA_RECOVERY_CODES]) {
    for (int i = 0; i < MFA_RECOVERY_CODES; i++) {
        char plaintext[32];

        // Generate random code (16 chars: XXXX-XXXX-XXXX-XXXX)
        generate_recovery_code_plaintext(plaintext, sizeof(plaintext));

        // Hash it before storing (use fast Argon2id since codes are random)
        codes[i] = hash_password_v3(plaintext, PWD_SECURITY_INTERACTIVE);

        // Display plaintext to user ONCE (don't store)
        display_recovery_code_to_user(plaintext);
    }
}
```

**Verify recovery code:**
```c
bool verify_recovery_code(const char *input, AUTH_DATA *auth) {
    for (int i = 0; i < MFA_RECOVERY_CODES; i++) {
        if (auth->recovery_used[i])
            continue;

        if (IS_NULLSTR(auth->recovery_codes[i]))
            continue;

        // Check if it's hashed (starts with $argon2id$)
        if (is_argon2id_hash(auth->recovery_codes[i])) {
            // New format: verify against hash
            if (verify_password_v3(auth->recovery_codes[i], input)) {
                return true;  // Valid code
            }
        } else {
            // Legacy format: plaintext comparison (for migration)
            if (strcmp(input, auth->recovery_codes[i]) == 0) {
                // Valid, but rehash it now
                char *hashed = hash_password_v3(input, PWD_SECURITY_INTERACTIVE);
                free_string(auth->recovery_codes[i]);
                auth->recovery_codes[i] = str_dup(hashed);
                free_string(hashed);
                return true;
            }
        }
    }

    return false;
}
```

**Migration strategy:**
- **New codes**: Hashed immediately on generation
- **Old codes**: Migrated on first use (when user enters plaintext code)
- **Security benefit**: Even if account JSON is stolen, recovery codes can't be extracted
